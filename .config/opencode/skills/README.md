Most SKILL files have been generated by LLMs (Claude Opus 4.6 among others). This has several advantages:

- It's well-known that allowing models to use longer reasoning traces allow them to come up with better results. In a way, we pre-generate useful concepts for the tasks at hand.
- We can validate those concepts in advance to align them with our own personal preferences.
- It offers more consistency between sessions with an agent. Without this, a model may come up with different guidelines, good or not.
- It can act as knowledge distillation when used with cheaper models.

Principles:

- We put guidelines into SKILL files instead of the prompt of agents to use less context tokens. Agents should be able to compose their knowledge as needed.
- We aim at keeping SKILL below 20KiB, which should be worth around 5500 to 6000 tokens.
- We don't want to duplicate information between SKILL files. Agents can load multiple SKILL files if needed.
- SKILL files should be cross-checked by another LLM.
- Avoid large code blocks, favor bullet points.
- Avoid ASCII art, favor mermaid diagrams.
